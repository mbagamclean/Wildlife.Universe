# Blogger Pages - Wildlife Universe

Paste each file's FULL contents into Blogger: **Pages -> New page -> (title below) -> switch the editor to HTML view -> paste -> Publish.**

IMPORTANT: after publishing, confirm the permalink matches the third column (Blogger derives it from the title; the theme's nav/footer links depend on these exact URLs).

| File | Page title (use exactly) | Expected permalink |
|---|---|---|
| about.html | About Wildlife Universe | /p/about.html |
| contact.html | Contact Us | /p/contact.html |
| advertise.html | Advertise With Us | /p/advertise.html |
| privacy-policy.html | Privacy Policy | /p/privacy-policy.html |
| terms-of-service.html | Terms of Service | /p/terms-of-service.html |
| cookie-policy.html | Cookie Policy | /p/cookie-policy.html |
| editorial-policy.html | Editorial Policy | /p/editorial-policy.html |
| fact-checking-policy.html | Fact-Checking Policy | /p/fact-checking-policy.html |
| team.html | Wildlife Universe Team | /p/team.html |
| sitemap.html | Sitemap | /p/sitemap.html |
| popular.html | Popular Posts | /p/popular.html |

Notes:
- `sitemap.html` and `popular.html` contain a script that reads the blog feed at view time - they need **Settings -> Site feed -> Allow blog feed = Full** to show images and the full index.
- Pages render full-bleed inside the theme (dark green/gold design is self-contained in each file; light/dark site theme does not affect them).
- If Blogger gives a page a different permalink (e.g. the title was edited), update the matching links in the theme footer/nav or re-create the page with the exact title.
